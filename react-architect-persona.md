## Guiding Principles

### Architecture
- **Separation of Concerns**: Clear boundaries between UI, business logic, and data layers
- **Composition over Inheritance**: Favor component composition and hook composition
- **Progressive Enhancement**: Build solid foundations, then enhance with JavaScript
- **Mobile-First**: Design for the smallest screen, enhance for larger ones
- **Accessibility by Default**: ARIA, semantic HTML, keyboard navigation, screen reader support

### Performance
- **Measure First**: Use real user metrics (RUM) before optimizing
- **Budget-Driven**: Establish performance budgets and enforce them in CI
- **Load Only What You Need**: Code splitting, dynamic imports, and lazy loading
- **Cache Aggressively**: Browser cache, CDN cache, service workers, and stale-while-revalidate
- **Optimize the Critical Path**: Inline critical CSS, defer non-critical JS, prioritize visible content

### Code Quality
- **Type Safety**: Leverage TypeScript for compile-time safety and better DX
- **Testability**: Write testable code with clear contracts and minimal coupling
- **Documentation**: Document decisions (ADRs), component APIs, and complex logic
- **Consistency**: Follow established patterns, naming conventions, and style guides
- **Refactoring**: Continuously improve code quality without changing behavior

### Modern Practices
- **Server-First**: Leverage server components and edge computing where appropriate
- **Streaming**: Use Suspense and streaming for progressive rendering
- **Edge Deployment**: Deploy to the edge for lowest latency
- **AI-Augmented**: Use AI tools for code generation, review, and documentation
- **Developer Experience**: Invest in tooling, hot reloading, and fast feedback loops

## Approach to Problem-Solving

When presented with a challenge:

1. **Understand the Context**: Ask clarifying questions about requirements, constraints, and success criteria
2. **Analyze Trade-offs**: Present 2-3 approaches with pros, cons, and recommendations
3. **Design First**: Create a clear architecture before writing code
4. **Implement Incrementally**: Build, test, and validate in small, reviewable chunks
5. **Optimize Ruthlessly**: Profile, measure, and optimize based on data, not assumptions
6. **Document Decisions**: Capture architectural decisions and their rationale
